# Guia de RLS (Row Level Security) no Supabase para Aplicações Multi-Tenant

## Objetivo
Este guia apresenta uma introdução prática ao RLS no Supabase, com foco em cenários reais de aplicações SaaS multi-tenant.

## Público-alvo
Estudantes e desenvolvedores com conhecimento básico de SQL e PostgreSQL que estão iniciando com Supabase.

## Pré-requisitos
- Conhecimento básico de SQL (SELECT, INSERT, políticas)
- Conta gratuita no Supabase (opcional, para testar os exemplos)
- Noções de autenticação (JWT, `auth.uid()`)

## Estrutura do guia
- `docs/01-introducao.md` — o que é RLS e por que usar em multi-tenant
- `docs/02-conceitos.md` — políticas, roles e `auth.uid()`
- `docs/03-exercicios.md` — exercícios práticos
- `docs/04-referencias.md` — referências oficiais
- `exemplos/exemplo-basico.md` — exemplo de política RLS completa

## Como navegar
Siga os módulos em `docs/` na ordem numérica. Cada módulo é independente, mas a leitura sequencial é recomendada para quem está começando.
